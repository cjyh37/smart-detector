# 스마트 디텍터

시험 시작 후 새로 수신된 무선 신호를 알려 주는 무료 Android 감독 보조 앱입니다.

소개와 다운로드: https://smartdetector.fwth.ai/

English: https://smartdetector.fwth.ai/en/

Google Play: https://play.google.com/store/apps/details?id=ai.fwth.smartdetector

Android 12 이상에서 사용합니다. iOS 버전은 개발 중입니다. 앱을 받은 뒤에는 인터넷 없이 쓸 수 있습니다. 인터넷에 연결되어 있으면 앱 사용 통계(Firebase Analytics)만 보내고, 수신한 신호와 검사 기록은 보내지 않습니다. 이 저장소는 소개 페이지용이며 Android 앱 소스 코드는 포함하지 않습니다.

다운로드 주소는 `download.json`의 Google Play 설정을 우선 사용합니다. 새 APK를 업로드하거나 GitHub Release를 만들어도 사이트의 다운로드 주소는 Google Play로 유지됩니다.

앱은 휴대폰이 수신한 신호와 그 변화만 보여 줍니다. 소유자, 좌석, 촬영 여부, 부정행위 여부는 확정하지 않습니다. 신호를 내지 않는 기기는 보이지 않을 수 있습니다.
