Smart Detector: foreground service demonstration

Release 0.11 (version code 2), ai.fwth.smartdetector. Recorded on an Android 15 emulator using the signed release APK.

Open or download the video directly

  1. Grant location, nearby-device and notification permissions from the app.
  2. Observe the reception screen, then return to the Android home screen.
  3. Open the notification shade: the ongoing “수신 중” (receiving) notification remains visible.
  4. Tap “수신 멈춤” (stop receiving). Return to the app and observe that it stays paused.
  5. Tap “다시 수신” (resume receiving) to start again.

The service supports ongoing Bluetooth/BLE and Wi-Fi signal reception for exam supervision. The location service type supports Android scan-result access; the app does not read GPS coordinates or track movement. This emulator recording shows the service lifecycle and virtual Wi-Fi signal, not a physical-device radio range test.
